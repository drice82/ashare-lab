# 月度定投规则（V0.2）

个人研究工具，仅支持单只沪深存续 A 股、月度固定投入。初始现金及持仓为零，无卖出。期末按原始收盘价估值，不能视为已经实现的税后收益。

## 输入与时间边界

股票、起止交易日、数据集版本映射必须显式提交；每月金额默认3000元，每月日期默认1日。API验证日期、上市范围、版本归属和完整日历；允许缺失可选数据集，但结果必须报告数据不足。当前同步流程只取得SSE日历，两市模拟复用该日历，不单独声称已验证SZSE日历。

计划仅生成于起止区间内。当月不存在指定日时取月末；休市顺延至区间内下一交易日。开始日期晚于当月计划日时，不补交当月资金。市场读取不超过结束日；每日决策只使用当日及之前行情和当时可确认公开的事件。供应商历史修订PIT尚未重建。

只分析固定基础信息版本中的存续证券，因此包含幸存者偏差。历史名称不会用于本模块的买入条件，也不使用当前名称判断历史ST；涨停约束读取固定版本的价格限制数据。

## 买入与账本

计划交易日先记入新资金，再尝试按当日未复权收盘价买入。休市已在计划中顺延；停牌、零成交量、收盘价达到涨停价时保留待成交计划，每个后续交易日重试，跨月多个计划合并为一次买入。缺失行情不等于停牌；缺失涨停价格不等于允许成交。

主板和创业板按100股整倍数，科创板至少200股，之后按1股递增。找到包含费用后余额可负担的最大股数。余额不足最低数量则结束该次尝试，余款等待下一期投入，不能每天用余款择价重试。

费用使用Decimal，每项四舍五入至分：佣金=max(成交额×佣金率，最低佣金)，另加成交额×过户费率；默认万三佣金、最低5元、过户费万分之0.1。佣金视为包含经手费与证管费；默认佣金率是账户模拟假设，不是统一官方费率。用户可以修改；整个区间固定使用提交参数，不重建历史费率。

参考：[上交所股票投资费用说明](https://one.sse.com.cn/onething/gptz/)、[交易佣金通知](https://www.chinatax.gov.cn/n810341/n810765/n812203/n813164/c1209808/content.html)、[科创板买入数量说明](https://edu.sse.com.cn/tib/)。

## 分红与未知结果

仅处理可确认公开、已实施的现金分红；必须有公告、实施公告、登记、除息及派息日期，现金每股口径明确且无送转股。以登记日收盘持仓确认权益（当日买入参与登记），派息日到账；非交易日派息在下一交易日账本处理并注明原派息日。同日处理顺序为到账、投入、买入、权益登记、估值。

到账分红参与下一次定投，若已有延期计划，则参与其下一次买入。已确认但未到账权益计为应收分红，不重复计入现金。重复事件按年度结束日/除息日去重，金额或关键日期冲突则结果未知。

没有卖出，因此分红暂按税前金额到账、已扣分红税为0；不提供卖出后补税结算，不能标为免税或卖出后的税后收益。参考[财税〔2015〕101号](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/201509/t418999.html)。

缺少分红完整覆盖时可展示现有数据计算的账本与曲线，但总资产、完整盈亏和收益率返回null并显示警告。缺少逐日必要覆盖、行情异常、事件不明或复杂公司行动时停止逐日计算，保留可核对部分；不得以零分红假装完整。

复权因子仅用于检查公司行动，不用于成交与估值。现金除息日预期因子比例为上一可确认收盘价/(该价格−每股现金分红)，允许0.1%比例误差；无法解释的变化返回未知。非已知现金除息日，仅在未停牌、当日前收盘参考价等于上一可确认收盘价、因子相对最近确认锚点累计变化不超过0.1%时允许继续，并保留微小变化提示；不据此推定额外现金或股份权益。不逐日重置该锚点，防止连续微小变化掩盖累计异常。缺失参考价或参考价不连续仍返回未知。此容差是一项模拟假设，不声称供应商已经证实变化原因。首版不处理送转、配股、拆并股；因子检查并不能弥补供应商漏报或历史修订。

## 输出与任务

总资产=现金+持仓市值+已确认应收分红；盈亏=总资产−累计投入；累计收益率=盈亏/累计投入。无投入时收益率为空。年化收益采用 XIRR：每次实际投入为负现金流，期末总资产为正现金流，按实际相隔天数/365 求解；无投入、投入及估值全在同日或无法求得有限唯一值时返回未知。最大回撤以初始净值1为基准，每次新投入按前一交易日净值增加份额，再按每日总资产估值；等价递推为净值×当日资产/(上日资产+当日投入)，包含费用、应收分红和现金，取历史峰值至后续谷值的最大跌幅。数据不完整时两项均返回null。不提供收益率排名。

新页面默认结束日为已发布最新行情日，开始日为结束日前一年（闰日落至目标年月底）、再顺延至该日历版本交易日。2/3/5年快捷按钮以当前结束日推算，只设置区间；日历不覆盖目标日时提示补齐或手选，不偷偷缩短期限。历史任务恢复原日期和原版本，快捷按钮不跨日历版本使用。汇总为紧凑四列表格，逐笔事件以文字标签和不同浅色背景区分。

停牌沿用区间内最近确认收盘价并显示估值日期；开头即停牌且没有持仓时市值为0。期末不能成交的资金保留现金，并展示待成交计划数。

SQLite jobs新增kind=dca，不增加表。结果为原子发布的不可变JSON，任务摘要保存文件引用。数据版本、引擎版本和股票池策略固定；重启按原版本全量重算，避免重复入账，旧算法不兼容时失败。succeeded表示计算过程完成，完整性另由summary.complete表示；partial仍只用于同步。

旧定投结果缺少新指标时，只从已保存的完整曲线计算，数据不足仍未知；不修改已发布JSON，不读取当前行情，保留旧股票池语义。微小因子变化校验修复后，新任务引擎版本为1.0.1；旧结果不自动重算，旧版本中断任务仍按版本不兼容保护拒绝恢复。

CSV导出完整账本及参数、版本、假设、完整性和警告。fixture模式在页面和结果中明确展示。单股回测已提供独立入口，见backtest-rules.md；组合、自定义策略、信号模块仍为计划开发。
