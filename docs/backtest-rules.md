# 单股回测（V0.3）

仅支持固定基础信息版本中的存续沪深A股，存在幸存者偏差。股票、起止交易日及数据版本必须显式指定；不访问当前数据头回退，不重建供应商历史修订PIT。

## 策略与日线成交

初始现金默认100000元，持仓为零。买入持有在开始日收盘产生一次信号，下一交易日开盘尝试买入。双均线默认20/60日，可配置2≤短周期<长周期≤250：前日短均线≤长均线、当日短均线>长均线为金叉；反向为死叉。开始已有多头不建仓，相等本身不产生信号。价格浮点误差在相对1e-12内视为相等。

从固定日历读开始日前长周期个交易日作为预热，以确认首日交叉；不足或窗口价格/因子缺失时完整结果未知。指标复用筛选因子模块的按信号日锚定复权价格；预热不成交。每日信号只读取截至当日的价格与复权因子，不使用后续价格归一化或未来公告。

收盘信号下一交易日按未复权开盘价模拟。停牌、零成交量、开盘价达到涨停时禁止买入、达到跌停时禁止卖出。延期订单逐交易日重试；收盘出现反向信号时撤销旧订单，仅在持仓状态需要时建立新订单。重复同向不加仓，余额不足结束该单。最后一天信号不强行成交。

一次投入，全仓买卖，无外部追加资金、杠杆、卖空或期末强制清仓。买入主板/创业板100股整数倍，科创板至少200股、之后1股递增；卖出清仓，包括零股余额。T日买入T+1才可卖出。每日顺序：已确认派息与相关税款、前日订单尝试、登记日权益、收盘估值、收盘信号。日线无法确认开盘集合竞价成交量、排队位置和部分停牌期间的实际成交；停牌记录按全日保守处理，结果仅为模拟。

## 费用与分红税

Decimal计算，各费用四舍五入到分。双向佣金=max(成交额×佣金率，最低佣金)，双向过户费=成交额×过户费率，卖出印花税=成交额×印花税率。默认0.0003/5元/0.00001/0.0005，用户可调整；全区间固定参数，不宣称是交易日期对应的历史实际费率，佣金包含经手及证管费。

现金分红公开可见性、日期顺序、去重冲突及复权核对复用定投规则。只登记当日收盘持仓，卖出后保留已有分红权益。送转、配股、异常因子或未知每股口径停止逐日计算，保留可核对部分；覆盖不足不假设零分红。

按买入批次先进先出、自然月/年计算分红税：不超过1个月20%，超过1个月至1年10%，超过1年0%。月末周年取目标月末；恰好月/年周年仍属于以内。规则来源：[财税〔2015〕101号](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/201509/t418999.html)、[官方持有期案例](https://shanghai.chinatax.gov.cn/zcfw/zcjd/201211/t400944.html)。首版仅计算登记日在2015-09-08之后的该税制，更早适用口径为未知。

派息日不卖出时税前到账；已到账分红卖出当日模拟扣税；卖出早于派息则计算确定税负，计负债，到账时扣除。非交易日派息下一交易日处理，假设开盘前资金可用。此日线资金时点是模拟假设，并非券商真实扣划时间。未卖出持仓不计算未来补税，结果不是期末全部清仓后的税后收益。

## 输出与持久任务

资产=现金+持仓市值+应收分红−确定未扣税负。盈亏=资产−初始现金，收益率=盈亏/初始现金。最大回撤从初始资金基准及每日资产峰值计算。停牌沿用最近可确认收盘价并记录估值日期。年化收益使用单笔初始投入的CAGR：（总资产/初始现金）^(365/回测日历天数)−1，天数从开始日至确认截至日；零时长、数据不完整或数值溢出时未知。定投的多笔现金流仍使用XIRR。不提供夏普、胜率、排名或基准比较。

任务kind=backtest，固定数据、引擎和策略版本；原子发布不可变JSON，重启按原快照全量重算，不兼容版本明确失败。succeeded仅表示计算过程结束，完整性必须检查summary.complete；未知时完整资产、盈亏、收益率、年化收益及最大回撤为null，曲线标注可计算部分。

完整CSV包含信号日、成交日、现金/持仓、费用/分红税、数据/引擎/策略版本、fixture_mode、参数、假设和未知原因，不受页面分页影响。fixture在页面与结果及导出中标注，组合回测见[组合回测规则](portfolio-rules.md)，自定义策略仍计划开发。

## 2026-10-10 展示与微小复权变化

回测复用定投的公司行动校验：非已知现金除息日，前收盘参考价连续且相对最近确认锚点累计变化在0.1%内时继续，保留模拟假设警告；停牌、缺失或不连续参考价不适用，容忍变化和稳定因子日均不重置锚点。已确认分红继续按现金除息比例校验，不推定任何额外现金或股份。新回测引擎1.0.1；旧已发布结果不自动重算，旧版本中断任务按不兼容保护拒绝执行。

新任务默认使用最新已发布行情日向前一年并顺延到固定交易日历的交易日；提供2/3/5年快捷设置，不自动提交。历史任务恢复原参数和版本，快捷设置不混用不同版本日历，日历不足提示手选或补齐。结果采用八行四列汇总表，手机端按指标/数值两列排列；逐笔账本按十一类事件显示文字标签及不同浅色背景。旧完整结果只用保存的初始资金、资产、起止日期补算年化，不读取当前行情或改写结果文件；旧不完整结果仍未知。

## 多策略对比（比较引擎1.0.0）

页面默认勾选六策略，也支持单选。每策略一组可调参数；股票、起止交易日、初始资金、固定数据版本及费用共同固定，各策略独立使用全部初始资金、现金、持仓与分红权益，不分摊资金。每种策略最多一组，同一任务最多六种；不自动寻优。

|策略ID|默认参数|信号|开始日前预热交易日数|
|---|---|---|---|
|buy_hold|无|沿用一次买入持有|0|
|ma_cross|20/60|沿用双均线交叉|长周期|
|macd_cross|12/26/9|DIF上穿DEA买入、下穿卖出|5×慢周期+信号周期|
|rsi_reversal|14日、30/70|RSI上穿下阈值买入、下穿上阈值卖出|5×周期+1|
|donchian_breakout|买入20日、卖出10日|收盘高于此前最高价买入、低于此前最低价卖出，窗口排除当日|两个窗口最大值|
|bollinger_reversion|20日、2倍标准差|收盘从下轨以下上穿下轨买入，上穿中轨卖出；同日买卖信号卖出优先|周期|

EMA先用首个完整周期简单均值初始化，再按2/(周期+1)递推；DEA先用首个完整信号周期DIF均值初始化。RSI为Wilder平均涨跌幅，零涨跌为50、仅上涨为100、仅下跌为0。布林带使用总体标准差。交叉为前日位于阈值一侧或相等、当日严格越过；新交叉相对误差1e-12（尺度至少1）内视为相等。指标按信号日锚定复权，不读取未来价格或因子。

各策略使用自己的固定预热起点，增加其他策略不改变递归指标种子。数据加载共享，预热完整性逐策略检查；不足、缺行情/因子、未知公司行动不延后开始日，不以其他策略的完整性补齐。交易、现金分红、税与未知边界继续复用单股引擎1.0.1。

累计收益率=总资产/初始资金−1，回撤曲线=总资产/此前峰值−1，峰值包含初始资金；最大回撤汇总为正值。买入持有被选中且完整时，收益差为策略累计收益率减买入持有累计收益率，页面单位为百分点；否则未知。不完整结果指标未知、排序置后，不绘制最终指标柱；曲线显示部分估算并止于可确认日期。日K线未复权，箭头为模拟成交日，信号日/费用/税从完整成交账本读取，延期不作为成交。

一个比较保存为一个backtest任务、一个不可变JSON；snapshot固定比较版本及每策略版本。重启全量重算，取消整个比较，程序异常整个任务失败；数据未知只影响对应策略。旧单策略请求与结果格式保留，不改变旧算法版本，不改写历史结果。导出分指标汇总、每日曲线、完整账本三类，均含策略参数、完整性、警告、数据/算法版本、fixture及模拟假设。
