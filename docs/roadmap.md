# 路线图

- V0.1：沪深A股数据仓库、版本/质量管理、六类筛选、中文Web与部署。
- V0.2：已实现单股月度定投、现金/持仓账本、交易费用和已确认现金分红；未卖出时分红税暂不扣，卖出补税及复杂公司行动待后续实现。
- V0.3：单股事件驱动回测，买入持有/双均线，T+1、停牌/开盘涨跌停约束、持有期分红补税及可复核账本。
- V0.4：已实现固定自选组合、逐股内置策略、共享账户、部分买卖、定期再平衡和买入持有基准。动态股票池、自定义策略（受限安全接口）为后续扩展。
- V0.5：已实现免注册日线信号通知、Bark与统一SMTP、无密码邮箱验证码登录、多设备会话及邮箱更换、持久调度/逐渠道重试及邮件专用退订；自动发送默认关闭，真实手机/邮件实收和退订验收后启用。

北交所代码迁移、分钟线及完整财务PIT为单独扩展；首版不加载分钟线。后续不得绕过已有DataProvider/MarketRepository/FactorEngine重新接行情或重复计算因子。
