# 组合回测（V0.4 / 引擎1.0.0）

固定选择1–20只数据版本中的存续沪深A股，每股配置一个内置策略。所有请求显式固定起止交易日和完整数据版本；存在幸存者偏差，不重建供应商历史修订PIT。动态选股、自定义代码、参数寻优和自动交易仍为后续能力。

## 权重、信号与周期

默认等权、初始现金100000元、月度再平衡。自定义权重使用小数比例，最多六位小数，逐股大于0且合计精确为1；等权模式不接受自定义权重。等权由后端计算，不要求客户端提交无法精确表示的三等份。所有资金只进入一个现金账户，不将各股独立回测收益相加。

每股沿用[单股策略](backtest-rules.md)的六种信号、参数、误差容限、预热长度和递归种子。预热不交易，增加其他股票不改变该股种子。初始持有资格关闭，买入持有在开始日收盘启用；其他策略只认区间内新信号，不因首日已有多头趋势而买入。买入信号启用，卖出信号关闭；重复同向信号不加仓。未启用股票对应的配置权重保留现金，不在其他股票间重新归一化。

周期支持none/weekly/monthly/quarterly/yearly，默认monthly。周期末取固定完整日历中该周、月、季或年最后交易日，不将回测结束日强行视为周期末。周按ISO周处理。收盘先更新持有资格，再进行周期再平衡，只调整已启用股票；已关闭股票目标为零。信号和周期同日时每股只生成一个最新目标，新目标撤销并替换旧目标。最后一天的指令不会强制成交，期末不强制卖出。

## 目标与成交

收盘净资产=现金+持仓市值+应收分红−确定未扣税负。冻结目标市值=该收盘净资产×配置权重（未启用为0），金额四舍五入到分。执行日只用未复权开盘价换算目标股数；主板/创业板目标股数向下取100股整倍数，科创板以1股计算。目标及生成日期随订单保存，延期仍使用原目标市值，不读取后续收盘或当前数据头。

同日先支付已确认现金分红及确定补税，再尝试卖出，最后处理买入。T日买入批次T+1才可卖出。主板/创业板买入至少100股、100股递增；部分卖出按100股整倍数，清仓包含零股。科创板买卖至少200股、超过部分1股递增；不足200股的持仓可以一次性清仓，但不能将较大持仓拆为不足200股的卖单。无法满足减仓单位时记录原因，等待下次目标调整。依据[上交所科创板说明](https://edu.sse.com.cn/tib/qa/)及[深交所卖出数量规定](https://www.szse.cn/lawrules/rule/trade/current/t20150914_565054.html)。

停牌、零成交量、开盘涨停禁止买入、开盘跌停禁止卖出，受阻目标逐交易日重试。停牌估值沿用最近可确认收盘价并注明日期。日线成交不模拟真实订单排队、竞价成交容量或实际部分成交，不保证券商可成交。

买入缺口=冻结目标市值−执行日开盘持仓市值。卖出完成后，向当天可交易且有买入缺口的股票按缺口比例分现金；各股预算不超过其缺口，费用计入预算，预算向下取到分。每股按合法数量和费用求最大可买股数。按股票代码稳定执行，其他股票的预算余款不重新分配。资金、费用或交易单位导致未买足时记录原因并结束本次买单，等下次周期再平衡或退出后的新买入信号。卖出受阻后释放的现金和后续分红不会自动补足已结束买单。

## 分红、费用与完整性

费用沿用单股回测，Decimal计算并四舍五入到分，双向佣金和过户费、卖出印花税；默认0.0003/最低5元/0.00001/0.0005，全区间固定，不声称为历史实际费率。

公开可见、已实施并有确定派息日期的现金事件在登记日按收盘持仓登记。权益按股票、买入批次分别维护，已卖出批次保留应收权益。部分卖出按先进先出拆分权益，分配最后一段剩余分币，保证已登记金额守恒；每个卖出部分按自己的买入日、卖出日确定税率，不重复补税。已到账权益卖出当日扣税，派息前卖出形成确定税负，派息到账时扣除。未卖出部分不预扣未来税。税率和自然月/年周年边界沿用单股规则，2015-09-08及更早登记的分红税制未知。

逐日执行前检查全部股票的行情、策略、复权和现金事件，避免一股数据未知后仍发布同日另一股已成交的混合状态。影响信号或资产口径的预热不足、缺行情、分红覆盖不足、未知送转/配股或异常因子导致该账户停止计算，保留此前可确认曲线、持仓和账本。完整资产、盈亏、收益率、CAGR和最大回撤为null；账户现金等字段仅代表可确认部分。无可确认持仓日期时持仓列表为空。

## 对照、结果和任务

基准使用相同股票、资金、初始权重和费用，全部买入持有并关闭再平衡，账户、批次、权益和现金独立。基准不要求实际策略的预热，因此实际组合未知时基准可能完整。两者分别标注完整性；仅两者完整时提供累计收益差，界面单位为百分点。基准不自动再投入分红。

累计收益率=净资产/初始现金−1；CAGR按开始日至确认截至日的自然日数、365天/年计算；最大回撤从包含初始资金的资产峰值计算。零时长或不完整时年化未知。每日持仓显示配置、资格目标和实际市值权重，实际权重分母包含现金、应收分红和确定税负。

一个portfolio任务包含实际组合和基准，一个不可变JSON保存曲线、逐日持仓、完整账本及原始OHLC。固定数据版本、组合引擎、依赖交易与信号版本；取消整个任务，程序错误失败，数据未知以succeeded和summary.complete=false明确区分。加载批次、逐日和发布前检查取消。恢复从原快照全量重算；不兼容版本失败，第三次运行中断停止自动恢复。不重写旧结果。

页面支持汇总、曲线、按日期持仓、逐股未复权K线和完整成交标记，以及实际/基准账本分页。四类CSV（summary/curves/positions/ledger）均导出两个账户的全量数据，包含参数、版本、fixture、完整性和假设；空的未知结果也保留元数据。fixture始终明确标注。
